# Rencana 1 — Fondasi: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `kasir.exe` hasil `task build` bisa dijalankan, membuka SQLite dengan pragma yang benar, menjalankan migrasi, menyajikan `/api/health` sesuai OpenAPI dan SPA React di `/kasir` dan `/owner`, dengan CI hijau di Linux dan Windows.

**Architecture:** Satu modul Go di `server/` dengan paket `internal/platform/*` (config, id, db, httpx) yang dipakai semua fitur berikutnya. Kontrak API di `api/openapi.yaml` menghasilkan kode server Go (oapi-codegen, strict server) dan client TypeScript (orval). Web React di `web/` di-build lalu di-embed ke binary Go.

**Tech Stack:** Go 1.27, modernc.org/sqlite, goose v3, BurntSushi/toml, google/uuid, oapi-codegen v2.8, kin-openapi (test), React 19, Vite 8, TypeScript strict, TanStack Router, TanStack Query 5, Tailwind 4, orval 8, Biome, Vitest, Playwright, go-task, GitHub Actions.

**Spec:** `docs/specs/2026-10-17-arsitektur-kasir-design.html` (bagian 2, 3, 4, 5, 9, 11, 12). PRD: `docs/PRD.html`.

> **Status (17 Okt 2026): DITUNDA.** Urutan kerja diubah jadi frontend dulu (lihat `docs/specs/2026-10-17-frontend-design.html`). Task 7 rencana ini dipindah dan diperluas ke rencana F1; sisa task (backend) dieksekusi setelah F1–F3 dan akan direvisi agar mengikuti kontrak `api/openapi.yaml` yang dipakai UI.

## Global Constraints

- Go `1.27` (direktif `go 1.27` di `go.mod`); build selalu `CGO_ENABLED=0`.
- Module path: `github.com/RidhoChan04/ShaziaMart/server`.
- OpenAPI versi `3.0.3`.
- Server hanya boleh listen di alamat loopback; default `127.0.0.1:8080`.
- Pragma SQLite: `journal_mode=WAL`, `synchronous=FULL`, `busy_timeout=5000`, `foreign_keys=ON`; satu koneksi penulis.
- SQLite yang dibundel harus ≥ `3.51.3`.
- ID entitas: UUIDv7 (string 36 karakter, huruf kecil).
- Waktu disimpan sebagai UTC milidetik epoch (`int64`).
- Uang selalu bilangan bulat rupiah; format tampilan `Rp12.500` (tanpa spasi, titik pemisah ribuan).
- Error API: `application/problem+json` (RFC 9457) dengan field `code` yang stabil.
- Semua teks yang dilihat pengguna dalam Bahasa Indonesia.
- Line ending LF (sudah diatur `.gitattributes`).
- Commit: author identitas git lokal pengguna; **tanpa** trailer `Co-Authored-By` atau tanda AI apa pun. Pesan commit gaya conventional (`feat:`, `fix:`, `chore:`, `test:`, `ci:`), boleh Bahasa Indonesia.
- Kode hasil generate di-commit; CI gagal bila hasil `task gen` berbeda.

## Review Focus

1. **File config belum ada** (instalasi pertama) → server membuat config default dan tetap jalan, bukan crash. Dites di Task 2.
2. **Path data mengandung spasi** (mis. `C:\Program Files\...`) → database tetap bisa dibuka. Dites di Task 3.
3. **Port sudah dipakai / instance kedua dijalankan** → proses keluar dengan pesan jelas dan exit code ≠ 0 sebelum menyentuh database. Dites di Task 8.
4. **Config berisi listen address non-loopback** (mis. `0.0.0.0:8080`) → ditolak saat load. Dites di Task 2.
5. **Refresh browser di deep link** (`/kasir/apa-saja`) → tetap mendapat SPA, bukan 404; sedangkan `/api/tidak-ada` → 404 problem+json. Dites di Task 8.
